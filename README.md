# 🎮 Show Case Repository

Этот репозиторий создан с целью **демонстрации текущего уровня понимания и умений в разработке игр**.

> ⚠️ Проект находится на ранней стадии развития. Код местами экспериментальный, местами учебный — прошу отнестись с пониманием.

---

## 🛠️ Используемые технологии и ассеты

| Технология | Назначение |
|---|---|
| **DoTween** | Анимации |
| **KinematicCharacterController** | Контроллер персонажа (немного адаптирован под нужды проекта) |
| **AllIn13dShader** | Основной шейдер проекта |
| **YandexSDK** | Интеграция SDK (использована слабо — проект в ранней стадии; игрался с шейдерами и их оптимизацией) |
| **NavMesh** | Навигация (используется точечно) |

Также в проекте задействовано **множество различных VFX и SFX ассетов**.

## 🎨 Материалы

В игре всего **2 материала**:

1. **Материал для интерактивных объектов**
2. **Материал для объектов сцены**

Такое решение позволяет минимизировать количество дравколлов и упростить управление рендерингом.

Все изменения их параметров происходят в классах:

- **`FullCustomShaderApplier.cs`**
- **`InteractiveObjectsShaderApplier.cs`**
